# Create the project

1. Sign in at [supabase.com/dashboard](https://supabase.com/dashboard).
2. Create a project named `inventory-lab`.
3. Enable Data API, Automatically expose new tables, and Enable automatic RLS.
4. Store the database password in a password manager.
5. Wait until the project status is healthy.
6. Copy the project URL from the project landing page. It looks like `https://<project-ref>.supabase.co`.
7. Open Project Settings → API Keys and confirm a publishable key and a secret key.

Keep the database password and the secret key out of this repo.
